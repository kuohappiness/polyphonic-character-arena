# 多音字擂台

一個可在手機、平板與電腦使用的繁體中文多音字配對遊戲。

## 開啟方式

- 線上版：部署完成後使用 GitHub Pages 網址。
- 本機版：直接開啟 `index.html`。

## 遊戲內容

- 首頁可搜尋多音字，也可直接點選字卡。
- 詞語顯示在飛機上，玩家要在飛彈落地前選出正確注音。
- 答錯或飛彈落地會顯示爆炸效果，錯題稍後再次出現。
- 可將錯題透過瀏覽器列印功能另存為 PDF。

## 檔案

- `index.html`：首頁、遊戲畫面與完成畫面。
- `styles.css`：桌機、平板、手機版面與動畫。
- `app.js`：多音字資料庫、搜尋、遊戲規則與錯題輸出。
- `CLAUDE_HANDOFF.md`：提供後續開發者或 Claude 的完整交接備忘錄。

這是純靜態網站，不需要安裝套件或執行建置程序。
